# Promoter Calculator Desktop 0.9.0

A desktop version of the open-source Promoter Calculator v1.0 for offline σ70 promoter transcription-initiation analysis. It is distributed as a self-contained HTML file and runs locally in Chromium on Windows and macOS. No installation, account, server, Python, or Node.js runtime is required for users.

If you use this app in your research, please cite the original paper:

LaFleur, T. L., Hossain, A. & Salis, H. M. Automated model-predictive design of synthetic promoters to control transcriptional profiles in bacteria. *Nature Communications* **13**, 5159 (2022). [https://doi.org/10.1038/s41467-022-32829-5](https://doi.org/10.1038/s41467-022-32829-5)
